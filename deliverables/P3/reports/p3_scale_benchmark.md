## 补充观察

- 从 `10k` 到 `1M`，token 数增加约 100.0 倍，构建耗时均值由 133.981 ms 增到 9347.904 ms。
- 线性拟合（build_ms = a * tokens + b）得到：a = 9.264001e-03 ms/token, b = 148.725 ms，拟合决定系数 R² = 0.9995。
- 平均归一化（ms/token）仍有波动，说明单位 token 成本不是严格恒定，可能受 IO、内存缓存、批次粒度等系统因素影响。
- 产物计数在各规模点上保持一致，说明这里测到的主要是**构建成本**，不是结构复杂度的变化。
- 由于每个点只有 3 次重复，当前图和拟合更适合作为“趋势确认”，而不是最终的性能定标结论。
