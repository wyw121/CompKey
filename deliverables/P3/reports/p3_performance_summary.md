# 第三阶段性能评估摘要

## 1. 评估口径

- 样本 seed 数量：8
- 采用数据源：P1 预处理结果与种子词表
- 数据库：SQLite
- 推荐模式：冷查询 / 缓存命中双模式

## 2. 指标结果

| 指标 | 数值(ms) |
|---|---:|
| 数据库初始化耗时(ms) | 41.648 |
| 离线导入耗时(ms) | 114.985 |
| seed查询平均耗时(ms) | 0.068 |
| seed查询中位数耗时(ms) | 0.066 |
| 推荐冷启动平均耗时(ms) | 0.103 |
| 推荐缓存命中平均耗时(ms) | 0.001 |
| 端到端总耗时(ms) | 175.123 |

## 3. 当前版本的优化建议

1. seed_keyword 与 candidate_keyword 已建立索引，查询路径更稳定。
2. 在线查询应优先使用缓存，避免重复排序。
3. 离线导入使用批量写入，减少事务开销。
4. 后续若并发增大，可将 SQLite 升级为 MySQL/PostgreSQL。
